# Security policy

## Supported versions

Security fixes are applied to the latest release line. Older snapshots are unsupported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for suspected vulnerabilities. Include the affected
version, impact, reproduction steps, and any proposed mitigation. Avoid public issues until a fix
or disclosure plan is ready, and never include credentials or private vault content in a report.

For ordinary correctness bugs without sensitive details, use a GitHub issue.
